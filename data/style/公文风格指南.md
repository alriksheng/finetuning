# 评审意见公文风格指南

**来源**：`04-审核意见` 中 116 份真实评审意见（企业处、农业处、外经处、教科文处、社保处、经建处、资环处、预算处，约 10.7 万字）和 `02-审核意见模板`，由 `scripts/extract_style_corpus.py` 抽取到 `style/corpus.jsonl`；并吸收前几轮专家反馈。

**适用范围**：只约束**模型撰写**的意见，包括提示核实、模型补充发现、证据不足项、合成样本，以及批量标注、蒸馏时生成的意见。依据可达的真实要点直接使用专家原话（见 `data/样本生成标准.md`），不按本指南改写。推理过程（think）也不受本指南约束。

## 一、篇章结构

1. 按部分组织：`基本情况部分`、`绩效基线分析部分`、`业务流程分析部分`、`成本核算分析部分`、`财政支出测定部分`，以及 `降本增效情况`、`“三个标准”建立情况`。贯穿全篇的问题（如分析范围）单列在前。**部分名只作标签，不写进意见正文**（专家第六轮意见），正文从问题或建议直接写起。
2. 一个部分有多条意见时，写成“一是……。二是……。三是……。”（不加部分名）；降本增效情况、“三个标准”按“1.……2.……”编号。
3. 组装由 `scripts/render_opinion.py` 完成，模型只输出每条意见的 `part`、`label`、`problem`、`suggestion`。

## 二、单条意见的句式

基本句式：**[问题定性或关键依据]，[建议/需/应 + 动作]，[目的]。**

| 成分 | 常见写法（取自真实意见） |
| --- | --- |
| 引出对象 | 针对……；……部分，；鉴于本项目……；从……来看 |
| 问题定性 | ……适配性不强；……合理性不足；结论支撑依据不足；……与……脱节；口径不一致；不具备比较意义；未打开至末端；约束力不足 |
| 依据举例 | 如……；（如……、……等）；括号内列出关键数字或表号 |
| 动作 | 建议补充／补充说明／需进一步细化／应围绕……／结合……／明确……／核实……／说明……的依据／加强……分析／重新测算 |
| 目的 | 以厘定……基准；为后续……奠定基础；以进一步降本增效；提高财政资金使用效益；便于后续管理改进和决策参考 |

**问题与建议不重复**。建议里已经写明要补什么，问题部分就不要再写“××未说明”。问题部分只写建议里没有的判断或证据。

- 不写：“考试费的执收和去向未作说明，建议补充考试费执收情况和去向。”
- 写：“考试费去向的相关金额散见于成本核算部分，建议补充说明考试收费管理、考试费执收情况，以及最终去向和不同去向的具体金额等信息。”

## 三、用词

| 统计项（每万字） | 真实意见 | 改写前（第三轮） | 改写后（第四轮） |
| --- | --- | --- | --- |
| 没有 | 0.2 | 21.5 | 0.0 |
| 只 | 0.3 | 25.8 | 0.0 |
| 也 | 1.1 | 21.5 | 0.0 |
| 未 | 15.9 | 41.6 | 28.2 |
| 仅 | 3.7 | 11.5 | 6.0 |
| 进一步 | 36.7 | 10.0 | 20.1 |
| 如 | 25.8 | 7.2 | 20.1 |
| 相关 | 33.2 | 5.7 | 14.1 |
| （ | 23.0 | 47.3 | 42.2 |
| 分句中位长度（字） | 53 | 65 | 67* |

\* 含“××部分，”等组装前缀。

- 判断留有余地：用“不够充分”“尚未充分”“需进一步明确”“衔接不足”“难以反映”，不用“完全”“脱钩”“反映不了”等绝对化说法；事实准确性要求见 `data/样本生成标准.md` 第七节。
- 否定用“未”“尚未”“缺少”“不足”，不用“没有”；限定用“限于”“集中在”“主要”，“仅”每条最多 1 次。
- 不用口语词：本小节、请到、看不到、没有、只、却、这些、我们（脚本拦截）。
- 多用“进一步”“结合”“围绕”“相关”“如……”。
- 措辞限于建议性质：建议／应／需。不用“驳回”“追究”等处置性表述。

## 四、引用与数字

- 引用报告：写表号和关键数字，不整句摘抄原文（与输入连续重合不超过 24 字，引号内不超过 12 字）。
- 每条只保留关键的一两组数字；数字必须在输入中，或是推理过程中已验证的计算结果。
- 不写条文编号；依据由程序按 `clause_ids` 补全文号后单独列出。条文中没有依据的，注明“（依据：评审经验）”。

## 五、长度（脚本检查）

- 每条意见（problem + suggestion）不超过 200 字；单个分句（以“。”“；”分隔）不超过 100 字。问题与建议合计超过 100 字时，在问题末尾用“。”断开。
- 每条括号不超过 2 处。

## 六、特殊类型

- **提示核实**：写“请核实：现有材料……，需核对第×章……，核实……，暂不作结论。”写明核对位置和内容，不下结论。
- **证据不足**：写明缺少什么资料、需补充什么，以及资料局限对结论的影响。
- **漏项逐项判断**：“有／无／需核实”，加上查找范围。
