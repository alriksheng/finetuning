```
【题目】
下列票据可以贴现的是
A. 商业汇票
B. 银行本票
C. 支票
D. 银行汇票

请作答。
```

```
<think>
【考点】本题考查哪些票据可以向银行办理贴现。贴现是持票人把未到期的票据转让给银行，银行扣除自贴现日至到期日的利息后，把余额付给持票人，本质上是一种以票据为担保的短期融资。
【规定】能够贴现的前提是票据本身有一段“未到期”的期限，也就是远期票据。商业汇票由出票人签发，约定在指定日期无条件付款，付款期限最长可达 6 个月，在到期前持票人可以背书转让，也可以向银行申请贴现。银行本票、支票和银行汇票都是见票即付的即期票据：银行本票由银行签发、见票即付；支票由出票人委托银行见票即付；银行汇票由出票银行签发，持票人在提示付款期内随时可以向银行兑付。即期票据随时可以直接取得款项，不存在“提前变现”的需要，所以不办理贴现。
【逐项分析】A“商业汇票”：远期票据，到期前可以贴现，正确。B“银行本票”：见票即付，不贴现。C“支票”：见票即付，不贴现。D“银行汇票”：同样见票即付，不贴现。
【延伸】商业汇票又分为商业承兑汇票和银行承兑汇票，两者都可以贴现，银行承兑汇票因为由银行承诺付款、信用更高，贴现更容易；贴现时持票人实际收到的金额等于票据到期值减去贴现息。
【自检】四种票据里只有商业汇票有付款期限，会计上也只有“应收票据贴现”这一业务对应商业汇票，结论一致。选 A。
</think>
答案：A。贴现针对未到期的远期票据，四种票据中只有商业汇票有付款期限，其余均见票即付。
```

## ACCT_002 · 工程项目管理 · CMMLU/construction_project_management/test/133 · 推理 495 字

```
【题目】
环刀法测定土层密度时，若环刀取在碾压层的上部，则测试数值与灌砂法结果
A. 无法比较
B. 偏小
C. 相等
D. 偏大

请作答。
```

```
<think>
【考点】本题考查压实度检测中环刀法的取样位置对结果的影响，以及与灌砂法的比较。
【原理】路基、基层分层碾压时，压路机的压实功从层顶向下传递并逐渐衰减，所以同一碾压层内上部最密实，越往下密度越小。灌砂法是在测点挖出整个碾压层厚度的试坑，用标准砂测出试坑体积，再用挖出材料的质量计算密度，得到的是整层的平均密度。环刀法只取环刀高度范围内的一小段土样，规程要求环刀应取在碾压层的中部，使它代表整层的平均密度。
【分析】如果环刀取在碾压层的上部，取到的是全层中最密实的部分，测得的密度会高于整层平均值，也就高于灌砂法得到的结果。反过来，取在下部会偏小。另外，环刀法本身只适用于细粒土和无机结合料稳定细粒土，对含粗颗粒的材料容易扰动，这也是规程把灌砂法作为基准方法的原因。
【逐项分析】A“无法比较”：两种方法测的都是湿密度并可换算干密度，可以比较，排除。B“偏小”：对应的是取在下部的情况，排除。C“相等”：只有取在中部、土层均匀时才大致相等，排除。D“偏大”：取在上部，密度高于整层平均值，正确。
【自检】结论依赖“上密下疏”的压实规律，这是分层碾压的普遍现象，也是规程规定取中部的原因。选 D。
</think>
答案：D。碾压层上部最密实，环刀取在上部测得的密度高于灌砂法反映的整层平均密度。
```

```
<think>
```
